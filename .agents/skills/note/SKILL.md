# note Markdown記法

noteエディタはMarkdownの一部のみに対応しています。
このSkillで確認されている記法のみで原稿を書くことで、noteエディタへの貼り付け時に正しく変換されます。

## 対応記法一覧

以下のみが対応記法として確認されている。
テーブル、脚注、リンク記法、画像記法、数式などの一般的なMarkdown記法は変換対象として確認されていないため、note貼り付け用原稿では使わない。

### 見出し

`## + 半角スペース`で大見出し、`### + 半角スペース`で小見出しになる。
noteはh2とh3のみに対応している。

```
## 大見出し
### 小見出し
```

h1、h4〜h6で貼り付けた場合の変換結果:

```
# 記事タイトル(h1) // h2に変換される
## 大見出し(h2)
### 小見出し(h3)
#### 見出し(h4) // h3に変換される
##### 見出し(h5) // h3に変換される
###### 見出し(h6) // h3に変換される
```

h1、h4〜h6は使わず、はじめからh2、h3のみで書く。

### 引用

`> + 半角スペース`で引用になる。

```
> Markdownとは、テキストを構造的に記述する「マークアップ言語」の1つです。
>
> Markdown記法を使えば、ショートカットキーや記号の入力によって、見出しや強調などの装飾や、戻る・進むなどの操作がしやすくなります。
```

他サイトや書籍から引用する場合は引用を使う。

### 箇条書きリスト

`- + 半角スペース`で箇条書きになる。`*`も使える。

```
- イヌ科
  - 柴犬
  - 秋田犬
- ネコ科
  - 三毛猫
```

注意事項:

- `-`と`*`を混在させると貼り付け時にうまく動かないため、どちらかに統一する。`-`への統一を優先する
- 階層分けのスペース数は厳密でなくても変換される
- 一覧の行頭にナカグロ(`・`)は使わず、ハイフン(`-`)またはアスタリスク(`*`)を使う

### 番号付きリスト

`1. + 半角スペース`で番号付きリストになる。

```
1. お湯を沸かす(90°C程度)
2. カップにインスタントコーヒー小さじ一杯を入れ、140mlのお湯を注ぐ
3. コーヒーを飲む
```

先頭は数字であればよく、同じ数字の並びや1以外から始めても表示は必ず1からになる。原稿では1からの連番で書く。

### 強調

`**`で囲む。`__`は前後に半角スペースが無いと変換されないため、`**`に統一する。

```
重要な箇所を**強調**します。
```

以下の違いに注意する:

```
重要な箇所を**強調**します。
重要な箇所を__強調__します。  // 変換されない
重要な箇所を __強調__ します。  // 変換される
```

### コードブロック

` ``` `で囲む。noteエディタでは` ``` `入力時点でブロックが開くが、原稿としては全体を` ``` `で閉じて囲む。

````
```
const name = "note";
```
````

### 取り消し線

`~~`で囲む。

```
文章中に~~取り消し線~~を入れます
```

### 区切り線

`---`で区切り線になる。

```
---
```

見出しを入れたくない場合の話題の区切りに使う。
